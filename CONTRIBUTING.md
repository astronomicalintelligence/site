# Contributing

Contributions to the site (workflows, prompts, skills, agent configs, model checks,
papers to review, failures, and updates to any of them) are proposed **only through
the issue forms**: <https://github.com/astronomicalintelligence/site/issues/new/choose>.

A maintainer reviews each proposal and labels it `needs-info` or `ready`. Ready
proposals are turned into pages and pull requests by the maintainers' daily job
(`tools/ISSUE_TO_PAGE.md`), so every page has the same structure, header and
catalogue number. The full guide is in [contribute.qmd](contribute.qmd).

Pull requests that add or change content directly are not accepted: please use the
forms instead. For a problem with the site itself, open a blank issue.

Contributions are published under the site licences: text under CC BY 4.0
([LICENSE-CONTENT.md](LICENSE-CONTENT.md)), code under MIT ([LICENSE](LICENSE)).
