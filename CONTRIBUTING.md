# Contributing

Thank you for helping. The full guide, with the page template and the review
criteria, is on the site: <https://astronomicalintelligence.org/contribute.html>
(source: [contribute.qmd](contribute.qmd)).

In short:

- **With Git:** add a `.qmd` file in `workflows/`, `prompts/`, `skills/`,
  `agent-configs/`, `model-checks/`, `reviews/` or `failures/`, with
  `author` and `date` in the header, and open a pull request.
- **Without Git:** [open an issue](https://github.com/astronomicalintelligence/site/issues/new/choose)
  and choose the matching template.

Run `quarto preview` to see your page before opening the pull request.
